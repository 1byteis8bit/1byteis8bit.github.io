# Portfolio

해커톤 제출용 AI·사이버보안 포트폴리오. 수상, 연구, 활동, 기술·관심 분야를 한 페이지에 정리했습니다.

## 수정 및 미리보기

- 내용: `index.html`
- 디자인 및 모바일·인쇄 스타일: `stylesheets/styles.css`
- 별도의 빌드나 패키지 설치 없이 `index.html`을 브라우저에서 열 수 있습니다.
- 로컬 서버: `python -m http.server 8000 --bind 127.0.0.1`

## GitHub Pages

계정명과 일치하는 `<username>.github.io` 저장소를 사용합니다.
Settings → Pages → Deploy from a branch → 게시 브랜치의 `/ (root)`를 선택합니다.
`.nojekyll`을 포함하므로 별도의 Jekyll 빌드 설정은 필요하지 않습니다.
