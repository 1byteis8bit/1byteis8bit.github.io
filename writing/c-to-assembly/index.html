A working mental model

C names values and operations. Assembly exposes where those values live and which instructions implement those operations. The translation is not one-to-one: optimization, ABI rules, and compiler decisions all shape the result.

Function calls

Under the System V AMD64 ABI, the first integer or pointer arguments normally arrive in rdi, rsi, rdx, rcx, r8, and r9. Integer return values use rax. This is the fastest bridge between a call site and its likely source semantics.

Stack frames

A familiar unoptimized function may save rbp, point it at the current stack, and reserve space by subtracting from rsp. Optimized code may omit that frame pointer entirely, so treat prologues as conventions rather than laws.

push rbp
mov  rbp, rsp
sub  rsp, 0x20
...
leave
ret

A repeatable reading strategy

  1. Mark calls, returns, and conditional branches.
  2. Identify argument preparation immediately before calls.
  3. Track values across registers and stack slots.
  4. Rename functions and variables as evidence accumulates.
  5. Verify hypotheses in a debugger.
