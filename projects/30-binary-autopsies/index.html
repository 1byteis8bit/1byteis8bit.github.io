30 Binary Autopsies

A structured practice series: thirty small ELF binaries, each examined through the same evidence-first analysis workflow.

Objective

Build fluency in moving between compiler output, disassembler views, and runtime state while producing a durable archive of techniques and observations.

Scope

Each entry covers initial triage, static structure, a dynamic investigation, the key behavior, and a small automation artifact where useful. Targets remain intentionally small enough for the analysis to be explained end to end.

Milestones

  • 01–10: control flow, calls, data representation
  • 11–20: common protections and compiler patterns
  • 21–30: automation and comparative analysis
